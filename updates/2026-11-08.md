## LinkedIn post
A review is only useful if it can embarrass you. This week a separate reviewer audited HoldSend's draft feature, where one draft is edited on two devices. It found that settling a conflict could close a version the person never saw, and that a phone could conflict with its own unsent edit after a reload. Both are fixed, and each fix has a test that fails on the old code. I checked that on purpose, because a test that passes either way proves nothing. The lesson: ask someone who did not write the code to try to break it. Code and notes: https://github.com/zyakuhq/holdsend
