## LinkedIn post
Small helpers can carry a lot of weight. This week HoldSend got the device side of two-device drafts: two tiny functions that decide what each edit is based on. The catch I wanted to avoid: one phone making two offline edits looks like a conflict with itself if both name the same server version. So an edit names this device's own unsent edit first, and only a person's explicit resolve closes real competing versions. The lesson: most conflict bugs hide in how a change names its parent, not in the merge. Next is a conflict screen in the example app. Code and guide: https://github.com/zyakuhq/holdsend
