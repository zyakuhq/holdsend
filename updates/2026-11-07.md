## LinkedIn post
Most sync bugs are not about speed. They are about which version wins. This week HoldSend got a conflict screen for one draft edited on two devices. When both devices changed the same version, the page shows each version and a person chooses, or writes one that uses both. The library never merges text and never picks a winner. A reviewer found a short window where a phone could conflict with itself, and we fixed it. The lesson: tell the person what happened, and keep every edit. Code and guide: https://github.com/zyakuhq/holdsend
