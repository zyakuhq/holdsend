## LinkedIn post, evening
Today I added a small check to HoldSend that I wish I had added earlier. A script reads the built type declarations of every package and writes them to a plain text record in the repository. If the build ever differs from the record, CI fails. The lesson: an API freeze is not a promise you make at the end, it is a habit you build before it. Most breaking changes are not decisions, they are side effects of a refactor nobody noticed. Now every change to what users import shows up as a diff in review. This comes right after 0.2.0 reached npm today, and it is the first step toward the 1.0 freeze planned for January. https://github.com/zyakuhq/holdsend
