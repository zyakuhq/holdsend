## LinkedIn post
Today I read every public type in HoldSend, line by line, before the 1.0 API freeze. The lesson: write down the rule before you start judging names. Mine was simple. Change something only if it confuses a reader, ties users to an internal file, or promises something we do not want to keep. A name that is merely not to my taste stays, because every rename costs every user an edit. That rule cut a long wish list down to five proposals for 1.0. Four small fixes that break nobody shipped today, and the API check now fails if a type points into an internal file. HoldSend is an open source library that keeps what people write on the device until it reaches the server, once. https://github.com/zyakuhq/holdsend
