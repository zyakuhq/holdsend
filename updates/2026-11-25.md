# 2026-11-25

## Done today

- Checks for the client `Store` contract ([#94](https://github.com/zyakuhq/holdsend/pull/94), [decision 0021](../docs/decisions/0021-client-store-contract-checks.md)). Anyone who writes their own store (SQLite, a file, a native module) had only prose rules to go by, and [production.md](../docs/production.md) said there was no test suite for them. Now [test/store-contract.ts](../test/store-contract.ts) has nine checks: concurrent updates lose nothing, the store keeps its own copies, nothing is saved when an update throws, every field comes back unchanged, a read never sees a half-written or emptied queue, and a store that says durable keeps its items. They run against all four built-in stores, and ten deliberately broken stores show each check can fail. Copy the file to test your own store; it is not published.
- Writing the checks showed the IndexedDB store returns items in key order, not the order they were saved. Nothing depends on that order, so the contract now says order is not promised, and that an update callback must be synchronous (the IndexedDB store already enforced it).
- A separate agent reviewed the checks and found eight problems, among them a durability check that only compared a flag, a read of an emptied queue that slipped through, and field order counted as a difference. All fixed.
- `main` CI stayed green.

## LinkedIn post

When a library lets people plug in their own storage, the rules for that storage are part of the API, even if they only live in a comment. HoldSend had those rules written down but nothing to test them with, so anyone writing their own store had to trust their reading of the prose. Today I turned the rules into nine checks that run against every store we ship. To make sure the checks are worth anything, I also wrote ten deliberately broken stores and required each one to fail. The lesson: writing the checks found a rule we had never stated. Our browser store returns items in a different order than they were saved. Nothing depended on it, but now the contract says so. https://github.com/zyakuhq/holdsend
