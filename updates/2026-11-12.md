## LinkedIn post

Today I got HoldSend ready for its 0.2.0 release, and found a gap I would have missed if I had only looked at the code.

The helpers for one draft edited on two devices were built, reviewed and tested, but the changelog and package READMEs never mentioned them. A release would have published an API nobody was told about. The lesson: before a release, compare what you export with what you have written down. Now the changelog says plainly that these helpers are early and may change in 0.3, and the smoke test loads every subpath on the oldest Node we support, so a release checks the packages as npm serves them.
