## LinkedIn post
Phone clocks are not to be trusted. If a phone's clock runs a few hours fast and is corrected later, a message written in between looks younger than it really is. HoldSend has a rule that a message waiting a day asks the person before it is sent, and a clock set back could slip a stale message past it. Now, when an item's written time is later than now, its real age is unknown, so it asks first. The lesson: every rule built on a device clock needs a case for the clock moving backwards. Today also added four browser tests for the emergency page, including the service worker sending with every page closed. Code and tests: https://github.com/zyakuhq/holdsend
