## LinkedIn post
Small bugs hide in the offline path. This week a review of HoldSend's example app found that a link with a query string, like a campaign tag, skipped the cached copy of the page, so the page failed to open without a connection. The fix was one option on the cache lookup. The lesson: write the test first and watch it fail on the old code, otherwise you do not know the test checks anything. HoldSend is an open source library that keeps what people write on the device until it has safely reached the server, once. The service worker, the cache and its tests are all in the repo: https://github.com/zyakuhq/holdsend
