# Update, Thu 5 Nov 2026

## Done today
- Server side of one draft on two devices: `acceptDraftUpdate`, `MemoryDraftLog` and `PostgresDraftLog` in `@holdsend/server`. Every well formed update is kept, never refused for a stale base, and numbered by the server. Two edits from one base give two open heads until a person resolves them. A retry adds nothing. Guide: [drafts.md](https://github.com/zyakuhq/holdsend/blob/main/docs/drafts.md).
- A separate reviewer read it before merge. Its findings were fixed: payloads and ids Postgres cannot store (NUL, lone surrogates), out of range `baseRev`, a size cap, memory and Postgres returning the same shape, and docs that said more than was true.
- Tests run on memory and PGlite, plus a real Postgres race test in CI. A stale-base refusal and a removed duplicate guard each made them fail.
