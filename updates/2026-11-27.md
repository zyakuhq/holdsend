# 2026-11-27

## Done today

- Checks for the draft log contract ([#98](https://github.com/zyakuhq/holdsend/pull/98), [decision 0023](../docs/decisions/0023-draft-log-contract-checks.md)). The server keeps every edit of a shared draft in a draft log, with versions for memory and Postgres. Anyone on another database writes their own. [test/draft-log-contract.ts](../test/draft-log-contract.ts) now has ten checks to copy and run against it: every field comes back unchanged, a retry adds nothing, every new update gets a higher revision, 25 appends at once all keep, a rolled-back append leaves nothing, and more. Twenty deliberately broken logs each fail the check meant to catch them.
- The new checks found a real bug in released code. `PostgresDraftLog` turned a payload that was the string `"42"` into the number 42, and the string `"null"` into no payload at all. `PostgresIdempotencyStore` did the same with a replayed answer whose body was such a string. Both now read their JSONB columns as text and parse that, so every driver gives back exactly what was stored. Objects and arrays, the usual case, were never affected.
- A separate agent reviewed the change. It confirmed the fix and found four gaps in the checks: empty values inside a payload were hidden by the comparison, a copied harness could skip a check without saying so, the fix had only run on PGlite, and two checks did not say what they expect. All fixed. Both server contract suites now also run through node-postgres on a real database in CI.

## LinkedIn post

Write the test for the interface, not for your own implementation. Today I added checks that anyone can copy to test the draft log behind HoldSend, our open-source outbox for apps that must work offline. The draft log keeps every edit of a note written on two devices. On its first run, the checks found a bug in our own Postgres version: a note whose whole text was "42" came back as the number 42, and the text "null" vanished. The code guessed whether the database had sent JSON or text, and for some strings it guessed wrong. Now it always asks for text and parses it, so there is nothing to guess. Twenty deliberately broken logs prove that each check can fail.
